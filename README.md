# PYTHIA

PYTHIA is a research design for testing whether calibrated forecasts can add value beyond prediction-market prices after realistic costs. The repository contains specifications and proposed experiments; it has no implementation, project forecast record, paper results or live trading results.

The primary hypothesis compares a market-anchored language-model ensemble with the market price and simple controls. A separate proposed weather strategy uses ensemble forecasts. The evaluation design specifies frozen cohorts, paired scoring, costs and explicit pass, fail or inconclusive outcomes. Gates are proposals and require confirmation before data collection.
