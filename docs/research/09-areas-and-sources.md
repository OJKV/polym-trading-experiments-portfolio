# 09 — Betting areas and their free data sources

> **Tested 2026-10-08.** The owner plans to bet on everything where free data exists, so this note maps *where the markets are* and *what free data covers each area*. **Method:** (1) a full crawl of Polymarket's public Gamma API (`/events/keyset`, about 225 pages) gave 22,441 active events and 268,110 active markets; each event was assigned to exactly one of 29 areas (plus a 30th residual bucket) by tag precedence (sport tags first, then mentions, weather, awards, crypto, stocks, health, science, economy, geopolitics, US elections, world elections, US politics, tech, culture), so the areas are disjoint and sum to the totals; per-tag cross-checks matched within a few percent (geopolitics is larger by design because it also absorbs Iran, Israel, Ukraine and military tags). (2) Eight researcher groups (US sports, world sports, esports and games, politics, economy and crypto, culture, science/tech/health/climate, mentions and competitions) tested every free-data endpoint live with one `curl` GET each on 2026-10-08, and (3) every endpoint was independently re-tested; disagreements are marked ⚠️ with the reason. This note **complements `docs/DATA_SOURCES.md`** (the canonical list); the lead merges rows from §3 and §4 into it. It adds no code and changes no other file.
>
> **Reading the tables.** *Priority* uses the DATA_SOURCES vocabulary (**v1**, **later**, **reject** = §5 only) but carries the *researchers'* ratings, not yet reconciled with DATA_SOURCES' phase rule (v1 only if a Phase 1-2 strategy or a safety gate needs it): 106 of the 303 rows in §3 are rated v1, so expect the lead to demote many to `later`. **v1†** = an undocumented but first-party or de-facto-official endpoint promoted to v1 as an exception to the "no undocumented endpoints" rule; the owner may demote it. *Tested* reads "researcher status / retest": ✓ = retest agreed, ⚠️ = retest disagreed (reason given; most are benign redirects or 200-versus-206). *Auth*: none, free key (env name in §4), account, paid.
>
> **Caveats that apply everywhere.** All tests ran from a macOS dev machine, not the remote isolated server, so every 403 from a WAF (Akamai, Cloudflare, DataDome) and every geo-block may behave differently on the isolated server: retest those from the isolated server before closing them. A few vendor pages (TheRundown, SportsGameOdds, odds-api.io, balldontlie, Polymarket fee docs, CFBD tiers, PandaScore, Alpha Vantage, EIA, Finnhub) were read through a summarising fetch tool, so re-read their free limits at signup. The unauthenticated GitHub API (60 requests per hour) was exhausted during research: fetch GitHub-hosted files through release or raw URLs, and create a token.

## 1. Area map

**Market structure in one paragraph.** 22,441 active events and 268,110 active markets, but only about 1,370 events (6%) trade more than $1k in 24h and only about 58 trade more than $100k. Sports tags cover 14,424 events (64%) and 238,076 markets (89%) yet only about $14.0M of about $40.0M 24h volume (35%): the market count is dominated by illiquid prop ladders and soccer micro-markets. Fee per share = `shares x rate x p x (1-p)` (takers only; makers pay nothing and earn a rebate), so the worst case at p=0.5 is rate/4: sports 0.05 = 1.25c, crypto 0.07 = 1.75c, politics/finance/tech/mentions 0.04 = 1.0c, NFL/CFB October rate 0.03 = 0.75c, geopolitics 0%.
